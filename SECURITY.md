# Security policy

Spent. handles personal financial records, so security reports are taken seriously.

## Reporting a vulnerability

**Please do not open a public issue for a security problem.**

Email **help@spentonline.in** with:

- what you found and where (URL or file),
- steps to reproduce it,
- the impact you think it has.

You will get an acknowledgement as soon as possible, and I will keep you updated while it is fixed. Please give a reasonable time to fix the issue before sharing details publicly.

## Scope

In scope: the app at [www.spentonline.in](https://www.spentonline.in) and the code in this repository, including authentication, access to other users' data, and the Android app.

Out of scope: social engineering, denial-of-service, and issues in third-party services (Supabase, Vercel, Resend, Google) that should be reported to them.

## Supported versions

Only the latest deployed version is supported.
